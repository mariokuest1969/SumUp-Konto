---
name: Deployment visibility / password protection
description: Where to find and change the password protection setting for published Replit apps.
---

The password protection (visibility) setting for a published app is NOT in the main publish dialog — it is under **"Adjust settings"** within the Replit Publishing UI.

**Why:** The main publish button reopens the standard dialog without visibility controls; "Adjust settings" is a separate section that exposes advanced options including Public / Password / Private visibility.

**How to apply:** When the user asks how to remove password protection or change visibility on a deployed app, direct them to open the Publishing tool and look for **"Adjust settings"**.
